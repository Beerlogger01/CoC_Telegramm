# Личный штаб на Telegram HTML Widgets — первая версия

Основание: main Beerlogger01/CoC_Telegramm c83ce58. Документация проверена 13 ноября 2026:
[Widgets](https://core.telegram.org/bots/widgets), [Bot API 10.4](https://core.telegram.org/bots/api#sendwidget).

## Архитектура

- `widget_template.py`: единый неизменяемый HTML/CSS/JS, цвета Telegram, компактная раскладка. Все динамические строки через textContent; никаких запросов к сети из шаблона.
- `widget_views.py`: проекции существующих API. Формулы и схемы бизнес-данных не меняются.
- `widget_store.py`: дополнительные SQLite-таблицы widget_screens/widget_preferences в существующем bindings.db. Владелец, message_id, срок 24 часа, случайный идентификатор, версия и разрешённые действия проверяются транзакционно. Повтор версии отклоняется до выполнения действия; выбор аккаунта хранится на сервере, не принимается из запроса.
- `widgets.py`: адаптер PTB 21.4 через его HTTP transport, без второго getUpdates. Новый Update сохраняется библиотекой в api_kwargs; ранний TypeHandler маршрутизирует widget_query. allowed_updates явно включает новый тип. Один запрос имеет 10-секундный бюджет работы и до 3 секунд на answerWidgetQuery. Данные приватны, public_data пустой.
- `bot.py`: подключение /menu, /widgets, /classic, получение событий; прежние групповые обработчики сохранены.

## Карта интерфейса

Штаб → КВ (счёт, разрушение, оставшиеся атаки); ЛВК (таблица, семь отдельных раундов); аккаунты/игроки → профиль → герои, снаряжение, реальные изменения 7/30/всё; рейтинги КВ/ЛВК; управление.

Управление открывает **существующие обычные Telegram-экраны** готовности, составов, голосований, руководства, привязки и аккаунтов. Они используют прежние проверки прав и подтверждения. Это законченный гибридный первый этап: изменение составов и голосований непосредственно внутри HTML, графики истории, объяснение рейтингов и подробные составы каждого раунда CWL в эту версию не входят. Backend пока не возвращает состав каждого раунда в `/cwl`; подмена его текущей войной не выполняется.

После истечения экрана или неоднозначного сетевого ответа открыть /menu. При отсутствии поддержки API отправляется прежнее меню. Старые Telegram-клиенты могут показать unsupported media; подпись содержит /classic, выбор сохраняется. Универсального сигнала поддержки клиента Bot API не предоставляет.

## Включение и откат

1. Сохранить резервную копию add-on обычными средствами Home Assistant.
2. После одобренного merge и **отдельного разрешённого выпуска образа 0.4.0** обновить add-on. Этот PR сам production не публикует. Существующий workflow main публикует образ при merge — учитывать при согласовании выпуска.
3. Установить `widgets_enabled: true`, перезапустить add-on и отправить /widgets в личном чате.
4. /classic возвращает обычный интерфейс конкретному пользователю. `widgets_enabled: false` отключает новый интерфейс глобально. Привязки, составы, голосования, история остаются на месте; новые таблицы можно оставить при откате.
5. Для Docker Compose передать WIDGETS_ENABLED=true в окружение бота.

Файлы конфигурации и launcher добавляют только новый переключатель. Токены и работающий Home Assistant не менялись. Автоматическое определение устаревшего клиента не заявляется.

## Проверки и границы

Офлайн: тесты через настоящий PTB Update/Application и подменённый HTTP transport; личные/групповые ограничения, серверная проверка аккаунта, повтор/чужой/устаревший запрос, SQLite после открытия заново, резервное меню, UTF-8 и zlib-9 лимиты, несколько аккаунтов. Существующие тесты групп, ролей, привязок, составов и backend входят в регрессию.

`preview.html` — визуальный макет с вымышленными данными и имитацией TelegramWidget. Это не снимок из Telegram и не проверка QuickJS-клиента. Приёмка на настоящих Android/iOS Telegram, Raspberry Pi и production Bot API требует отдельного запуска. Секреты и реальные API не использовались.

Локальный результат: 106 тестов бота, 59 backend и 5 launcher/config прошли; ruff F и compileall проходят. Шаблон: 2597 UTF-8 байт / 1184 байт zlib-9. Визуальный макет в Chromium при ширине 320 px занимает 325 px высоты, ошибок JavaScript нет. Это не подтверждает полную совместимость QuickJS Telegram.
