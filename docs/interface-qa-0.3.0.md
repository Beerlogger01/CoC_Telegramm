# Проверка интерфейса 0.3.0

Дата: 2026-11-05. Проверка воспроизводима без токенов CoC/Telegram и без отправки сообщений настоящим участникам.

Тесты `bot/tests/test_full_interface.py` запускают настоящий `python-telegram-bot Application`, производственный `register_handlers` и реальные SQLite-хранилища. Заменяются только HTTP-ответы CoC-бэкенда и транспорт Telegram. Набор данных: 50 игроков, 24 привязанных аккаунта одного пользователя, специальные символы/emoji в никах, 29 предметов снаряжения, недоступный раунд посередине ЛВК.

| Раздел/ошибка | Что проверено |
| --- | --- |
| Главное меню | Все разделы, кабинет руководства и возврат в штаб |
| Игроки | Все страницы, последняя карточка, герои и снаряжение, возврат на исходную страницу |
| Мои аккаунты | Пять страниц, смена основного, подтверждение удаления, развитие и периоды |
| Рейтинги | Все 50 игроков, объяснение балла, КВ/ЛВК, изменение размера КВ, пустые категории |
| ЛВК | Кнопки 1–7, недоступный второй раунд, корректный третий, таблица, обновление |
| Текущая война | Постранично все оставшиеся атаки, в том числе 1/2; возврат |
| История | Страницы войн и всех участников, звёзды и TH целей |
| Привязка | Все страницы свободных игроков, ручной ввод, безопасный ник, отмена, неверный/верный тестовый токен |
| Сохранённый состав | Выбор размера, редактор и страницы, замены, публикация, редактирование того же сообщения, закрытие |
| Готовность | Отдельные аккаунты, улучшение героев блокирует публикацию, новый сбор не наследует ответы |
| Права и гонки | Чужой callback, отозванная роль, вышедший/недопущенный игрок, изменение ответов до публикации, старая версия состава |
| Голосования | Вопрос, варианты, удаление последнего, срок, предпросмотр, один изменяемый голос, итоги и список |
| Telegram | Один экран на последовательность переходов, старая кнопка, повтор update, удалённое сообщение, истечение срока, Message is not modified, ошибка разметки |
| Перезапуск | Ответы и составы сохраняются; чужой прежний ответ после перепривязки не учитывается; рассылки не повторяются |
| Сеть | Ошибки источников, неоднозначная доставка и блокировка повторной отправки |
| Форматирование | Валидный HTML, длина сообщения до 4096 UTF-16 единиц, callback до 64 байт |
| Команды | Существующие команды справки, профиля, клана, отчёта, настроек и управления проходят через тот же интерфейс |

Дополнительные тесты проверяют гонку двух публикаций, срок сбора, полный состав 50 игроков без обрезания, реальные номера раундов бэкенда, небольшой бонус звания и сохранение пользовательских весов.

Команды проверки (из корня):

```bash
python -m compileall -q backend bot coc_telegram
ruff check backend bot coc_telegram --select F
PYTHONPATH=backend python -m pytest -q backend/tests
PYTHONPATH=bot python -m pytest -q bot/tests
PYTHONPATH=. python -m pytest -q coc_telegram/tests
```

Проверено локально на Python 3.11, как в образе аддона; также выполнялись проверки на Python 3.12. Проверка не является тестом на настоящем аккаунте Telegram и не подтверждает права/сетевую доступность конкретной установки Home Assistant. Реальная доставка зависит от Telegram, CoC API и прав бота. Docker-сборка выполняется workflow репозитория; локальный Docker daemon в этой среде недоступен.

После установки: открыть `/menu` в личке и группе, проверить реальные ники и таблицу ЛВК, создать пробный сбор и один короткий опрос. После обновления старые меню нужно открыть заново.
